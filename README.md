### 🔭 Projetos em Destaque

#### 🐝 [Bee / Tom&Mei — E-commerce Full-Stack](https://github.com/matheuslemes1/base-mini)
E-commerce completo para venda de roupas infantis, do carrinho ao pagamento — **em produção**.
- 💳 Checkout real com **Mercado Pago** (Payment Brick + webhook de confirmação)
- 📦 Estoque em tempo real por tamanho, com baixa automática e histórico de movimentações
- 🚚 Cálculo de frete via API **Melhor Envio**
- 🔐 Painel admin protegido por middleware (CRUD de produtos, categorias, estoque, pedidos e insumos)
- 📧 E-mails transacionais automáticos (confirmação ao cliente + notificação de venda)
- **Stack:** Next.js 16 · TypeScript · Supabase · Tailwind CSS v4 · Zustand

`Next.js` `TypeScript` `Supabase` `Mercado Pago` `Tailwind CSS`

#### 📋 [Laliê Admin — Painel de Gestão para Papelaria](https://github.com/matheuslemes1/lalie)
Sistema interno para gestão de uma papelaria personalizada: despesas, catálogo, clientes e orçamentos.
- 📊 Dashboard com métricas em tempo real (gastos, produtos, orçamentos, faturamento)
- 📄 Gerador de orçamentos com cliente autocomplete, busca de CEP (ViaCEP), cálculo de subtotal/total ao vivo
- 📥 Exportação de orçamento em **PDF** e compartilhamento nativo (Web Share API)
- 💰 Controle de margem de lucro por produto, com indicador visual (verde/amarelo/vermelho)
- **Stack:** Next.js 16 · TypeScript · Supabase · React Hook Form + Zod · jsPDF

`Next.js` `TypeScript` `Supabase` `React Hook Form` `Zod`
